# DROPTURN — 落として回す立体三目並べ

3×3×3のかごに色の箱を落とし、段を回すか全体をひっくり返して、同じ色を3つ並べる立体の三目並べ。1台で2〜4人。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/dropturn/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1 台の端末を回して 2〜4 人で遊ぶ。自分の番に、次のどれか 1 つをする。

- **落とす**: 自分の色の箱を 1 つ、好きな列の上から落とす。
- **回す**: 上・中・下のどれかの段を 90° 回す。下が空いた箱は落ちる。
- **返す**: かご全体を上下にひっくり返す。

どの面でも、同じ色を縦・横・斜めに 3 つ並べたら勝ち。一度出たかごの形（かごごと回しただけの形も同じ）に戻す手は指せない（囲碁のスーパーコウと同じ考え方）。「落とす」は箱が増えるので制限なし。
全員の手持ちがなくなってから 12 手そろわなければ引き分け。「↺」で直前の 1 手だけ取り消せる。

かごは本物の 3D（Three.js）で、空いた所をドラッグすると周りを回って見られる。「⟲」で視点を正面に戻す。

タイトルの「CPU と対戦」を選ぶと、2 人のうち 1 人を CPU にできる（手番・強さを選べる）。「観戦」なら両方が CPU で、勝手に対局が進む（一時停止・速さを選べる）。CPU は DROPTURN の研究で作った AI。どちらも公式ルール・2 人のときだけ選べる。

- **落とす**: 手持ちの色の箱を指で押さえ、かごの上までドラッグして、光る入口の上で離す。入口から外れた所で離すと戻る。
- **回す**: かごの段を指でタップ（動かさずに離す）。離した場所がかごの中心より右なら右回り、左なら左回りに、その場で 90° 回る。
- **返す**: 「返す」→ 確認して、かご全体を上下にひっくり返す。

## エクストラルール

タイトルの「公式 / エクストラ」で切り替える（対局中は変わらない）。公式ルールはそのまま、
軸をなくして 3×3×3 = 27 マスすべてに箱が入る、より自由な遊び方。

- 落とす入口は上面の 9 列すべて。
- 勝ちの線は縦・横・柱・面と断面の斜め・立体の対角線を含む全 49 本。真ん中を通る線や立体の対角線でもそろえば勝ち。
- **回す**: 横（今までの段）だけでなく縦の 1 枚も回せる。かごの面のマスを長押しすると矢印が出て、
  矢印の上で指を離すと、そのマスを通る 1 枚がその向きに回る（矢印は隣のマスとの境目の辺に接して出る。面の端では自分のマスの辺に出る）。
- **倒す**: 「返す」→ 手前・奥・左・右（今の見た目の向き）にかご全体を倒すか、上下ひっくり返すかを選ぶ。
- 1 手前に戻る手の禁止・引き分け・「↺」は公式と同じ考え方。手持ちの数は 27 マスを人数・色でできるだけ均等に配る
  （24 と違い割り切れないので、色によって 1 個の差が出ることがある）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

遊びの中身（かご・落とす・回す・返す・重力・戻す手の禁止・勝敗判定）は `game.js`（公式）・`game-extra.js`（エクストラ、軸なし 3×3×3）に
まとまっていて、DOM に触らないので Node だけで確かめられる。CPU の思考は `cpu/engine.mjs`（探索。DROPTURN の研究と同じもの）・
`cpu/cpu.mjs`（根の手を選ぶ）が受け持ち、`cpu/worker.js`（Web Worker）から呼ぶ。どちらも DOM には触らない。

```sh
node test.mjs
```

- 3D は [Three.js](https://threejs.org/)（MIT）を使用。`vendor/three.module.min.js`（r170、1 ファイルの ES module）を同梱し、ライセンスは `vendor/three.LICENSE`。
  r171 以降はビルドが 2 ファイルに分かれるため、1 ファイルで済む r170 を使っている（SKEWLINE と同じ版）。
