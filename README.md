# DROPTURN — 落として回す立体三目並べ

3×3×3のかごに色の箱を落とし、段を回すか全体をひっくり返して、同じ色を3つ並べる立体の三目並べ。1台で2〜4人。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/dropturn/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1 台の端末を回して 2〜4 人で遊ぶ。自分の番に、次のどれか 1 つをする。

- **落とす**: 自分の色の箱を 1 つ、好きな列の上から落とす。
- **回す**: 上・中・下のどれかの段を 90° 回す。下が空いた箱は落ちる。
- **返す**: かご全体を上下にひっくり返す。

どの面でも、同じ色を縦・横・斜めに 3 つ並べたら勝ち。1 手前の局面に戻す手（直前の人の回す・返すをそのまま打ち消す手）は指せない。
全員の手持ちがなくなってから 12 手そろわなければ引き分け。

操作は「選ぶ → 薄い予告 → 決定」の 2 段階。帯（かごを開いた展開図）が操作の本体で、上の小さな図は見るだけ（⟲ で見る向きを変える）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

遊びの中身（かご・落とす・回す・返す・重力・戻す手の禁止・勝敗判定）は `game.js` にまとまっていて、
DOM に触らないので Node だけで確かめられる。

```sh
node test.mjs
```
